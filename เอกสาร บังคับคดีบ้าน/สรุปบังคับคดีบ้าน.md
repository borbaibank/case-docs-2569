## วิเคราะห์สถานะธนกร

### ธนกรไม่ต้องการผ่อนต่อ — ไม่มีเงินผ่อน

**สิ่งที่ต้องรู้:**
1. **แปลงที่ 2 ธนกรเป็นเจ้าของร่วม** — เมื่อขายทอดตลาดแล้ว เงินที่เหลือหลังหักหนี้จำนอง SCB จะ **ต้องแบ่งให้ธนกร** ในส่วนที่เป็นเจ้าของ
2. **ถ้าปล่อยให้ขายทอดตลาด** จะขายต่ำกว่าราคาตลาด — ธนกรเสียประโยชน์
3. **จำนอง SCB = ต้องหักจ่ายธนาคารก่อน** — ถ้ายอดหนี้คงเหลือสูง อาจเหลือน้อยมาก

### ทางเลือกของธนกร

#### ทางเลือก A — ปล่อยให้ขายทอดตลาด (ง่ายที่สุด)

**ข้อดี:**
- ไม่ต้องจ่ายอะไรเพิ่ม ไม่ต้องผ่อนต่อ
- หนี้ SCB จะถูกหักจากเงินขาย

**ข้อเสีย:**
- ราคาขายทอดตลาดมักต่ำกว่าตลาด 30–50%
- ถ้ายอดหนี้ SCB > ราคาขาย → **ธนกรอาจถูกทวงส่วนต่าง** (ถ้าเป็นลูกหนี้ร่วม)
- เสียส่วนแบ่งเจ้าของร่วมที่ควรได้

**เงินคร่าวๆ:**
- ถ้าขายได้ 2.5 ล้าน หักหนี้ SCB (สมมติเหลือ 2 ล้าน) → เหลือ ~5 แสน → ธนกรได้ครึ่ง = **~250,000 บาท**
- ถ้าขายได้ 3 ล้าน หักหนี้ 2 ล้าน → เหลือ 1 ล้าน → ธนกรได้ **~500,000 บาท**

#### ทางเลือก B — ไปเสนอราคาเอง (ซื้อกลับ)

**ข้อดี:**
- ซื้อบ้านตัวเองในราคาต่ำกว่าตลาด
- ถ้าเงินประกันลดตาม "คำสั่งศาล/คู่สมรส" ใช้เงินน้อย (128,000 บาท)

**ข้อเสีย:**
- ต้องมีเงินจ่ายภายใน 15 วัน
- ถ้าไม่มีเงินผ่อน — ต้องกู้ใหม่หรือหาคนร่วมซื้อ

> ❌ **ไม่เหมาะสำหรับธนกร** เพราะบอกว่าไม่มีเงินผ่อน

#### ทางเลือก C — ขายส่วนของตัวเอง / เจรจากับปรารถนา

**ข้อดี:**
- ไม่ต้องรอขายทอดตลาด
- อาจได้เงินมากกว่าปล่อยขายทอดตลาด

**ข้อเสีย:**
- ต้องเจรจากับปรารถนา (อาจยาก เพราะมีคดีกัน)
- ใช้เวลาและอาจต้องผ่านทนาย

#### ทางเลือก D — คัดค้านราคาประเมิน / ขอเพิ่มราคาขั้นต่ำ (แนะนำ)

**ข้อดี:**
- ราคาประเมิน LED ต่ำกว่าตลาดมาก → **มีเหตุขอศาลให้ปรับราคาเริ่มต้น**
- ถ้าราคาเริ่มสูงขึ้น ธนกรได้ส่วนแบ่งมากขึ้น

**วิธี:**
1. ปรึกษาทนายเรื่อง **คำร้องคัดค้านราคาประเมิน** ก่อนนัดแรก (14 ต.ค.)
2. ยื่นเอกสารราคาตลาดจากเว็บประกาศขาย (3.6–4.2 ล้าน) เทียบกับราคาประเมิน (2.56 ล้าน)
3. ขอให้เจ้าพนักงานประเมินใหม่ หรือกำหนดราคาเริ่มต้นสูงขึ้น

**ข้อเสีย:**
- ถ้าราคาเริ่มสูง คนเข้าแข่งน้อย อาจไม่มีคนซื้อ → ต้องรอนัดถัดไป

## สิ่งที่ธนกรควรทำตอนนี้

1. **ตรวจยอดหนี้ SCB คงเหลือ** — เท่าไร สำหรับทั้ง 2 แปลง
2. **ถามทนายว่าเป็นลูกหนี้ร่วมกับ SCB หรือไม่** — ถ้าใช่ และขายไม่พอหนี้ → ธนกรอาจถูกทวงส่วนต่าง
3. **พิจารณาคัดค้านราคาประเมิน** แปลงที่ 2 (ทางเลือก D) — มีหลักฐานชัดว่าตลาดสูงกว่ามาก
4. **เข้าร่วมวันทอดตลาด** (ไม่ต้องซื้อ แต่ไปดูราคาจริง) — ถ้าราคาต่ำเกินไปอาจขอค้าน ณ ที่นั้น
5. **ถ้าปล่อย → อย่างน้อยไปรับส่วนแบ่ง** จากเจ้าพนักงานหลังขาย

### ⚠️ สถานการณ์อันตราย

**ถ้าขายทอดตลาดได้ต่ำกว่า 3.2 ล้าน:**
- เงินไม่พอจ่าย SCB → **ธนกรอาจถูกทวงส่วนต่าง** ในฐานะลูกหนี้ร่วม
- เช่น ขายได้ 2.5 ล้าน → ขาด 7 แสน → SCB อาจทวงจากธนกร

**ถ้าขายได้ 3.6 ล้านขึ้นไป:**
- หักหนี้แล้วเหลือ → ธนกรได้ส่วนแบ่ง
- แต่ต้องหักค่าค้างของปรารถนา 3 แสนด้วย

### ⚠️ เรื่องค้าง 3 แสนของปรารถนา

- ปรารถนาไม่จ่ายค่าผ่อน → **ธนกรอาจถูก SCB ทวงแทน** (ถ้าเป็นลูกหนี้ร่วม)
- **ตรวจสอบด่วน:** ธนกรเป็นผู้กู้ร่วมหรือไม่? → ถ้าใช่ SCB มีสิทธิทวงจากธนกรเต็มจำนวน
- ถ้าธนกรจ่ายแทน → มีสิทธิไล่เบี้ยจากปรารถนา แต่ต้องฟ้องเอง

### คำแนะนำเร่งด่วน

1. **ตรวจสัญญากู้ SCB** — ธนกรเป็นผู้กู้ร่วม/ค้ำประกันหรือไม่
2. **ถ้าเป็นผู้กู้ร่วม** → ปรึกษาทนายเรื่องรับผิดหนี้ค้าง + ไล่เบี้ยจากปรารถนา
3. **คัดค้านราคาประเมินยิ่งสำคัญ** — ต้องให้ขายได้ >3.2 ล้าน ไม่งั้นธนกรเสียหาย
4. **เตรียมหลักฐานราคาตลาด** (3.6–4.2 ล้าน) ยื่นก่อนนัด 14 ต.ค.
5. **ถ้า SCB กำลังฟ้องธนกร** เรื่องค้างผ่อน → ต้องจัดการคู่กัน

## อัปเดต: ธนกรเป็นผู้กู้ร่วม SCB

**ผลกระทบ:**
- SCB มีสิทธิทวงหนี้จากธนกร **เต็มจำนวน** (ไม่ใช่แค่ครึ่งเดียว)
- ค้าง 3 แสนที่ปรารถนาไม่จ่าย → **SCB ทวงจากธนกรได้ทันที**
- ถ้าขายทอดตลาดไม่พอหนี้ → **SCB ฟ้องธนกรเรียกส่วนต่างได้**

## กระบวนการขายทอดตลาด — ไม่ใช่ขายตามราคาประเมินทันที

### ราคาประเมิน 2.5 ล้าน = ราคาเริ่มต้นขั้นต่ำ ไม่ใช่ราคาขาย

**ราคาประเมินของกรมบังคับคดี (LED)** เป็นแค่ **ราคาตั้งต้น** ในการเปิดประมูล:

1. เจ้าพนักงานประกาศราคาเริ่มต้น (อิงจากราคาประเมิน)
2. **ผู้สนใจเข้าเสนอราคาแข่งกัน** (ประมูล) — ใครให้ราคาสูงสุดได้ไป
3. ราคาสุดท้ายอาจ **สูงกว่าราคาประเมินมาก** ถ้ามีคนแข่งหลายราย
4. แต่ราคาสุดท้ายอาจ **ต่ำกว่าราคาตลาด** เพราะคนซื้อทอดตลาดรู้ว่ามีความเสี่ยง (ผู้อยู่อาศัยไม่ย้าย, สภาพบ้าน ฯลฯ)

**ตัวอย่าง:**
- ราคาประเมิน = 2.5 ล้าน
- นัดแรก: คนเข้าแข่ง 3 ราย → ประมูลขึ้นไป → ขายได้ **3.2 ล้าน** (เกินราคาประเมิน)
- หรือ: มีคนเดียว → ได้ไปที่ **2.5 ล้าน** (ราคาเริ่มต้น)

### ทำไมนัดหลายครั้ง (6 นัด)?

**เหตุผลหลัก: ถ้านัดแรกไม่มีคนซื้อ หรือราคาต่ำเกินไป**

| นัด | กลไก | ราคา |
|-----|-------|------|
| **นัดที่ 1** | เปิดประมูลราคาเริ่มต้นสูงสุด | ≥ ราคาประเมิน (~2.5 ล้าน) |
| **นัดที่ 2** | ถ้านัดแรกไม่มีคนซื้อ → **ลดราคาเริ่มต้นลง** | ลดลง ~10–20% |
| **นัดที่ 3** | ลดอีก | ลดลงอีก |
| **นัดที่ 4–6** | ยิ่งไม่มีคนซื้อ ยิ่งลดราคา | อาจลดถึง 50% ของราคาประเมิน |

**หลักคือ:**
- **นัดแรก = ราคาดีที่สุด** (เริ่มสูง)
- **นัดหลังๆ = ราคาลดลงเรื่อยๆ** จนมีคนยอมซื้อ
- ถ้านัดสุดท้ายยังไม่มีคนซื้อ → เจ้าพนักงานอาจถอนการขาย หรือประเมินใหม่

### ผลต่อธนกร

| สถานการณ์ | ผลลัพธ์ |
|-----------|---------|
| ขายนัดแรกได้ 3.5+ ล้าน | **ดีที่สุด** — หักหนี้ 3.2M เหลือส่วนแบ่ง |
| ขายนัดแรกได้ 2.5 ล้าน | **แย่** — ขาด 7 แสน SCB ทวงจากธนกร |
| ไม่มีคนซื้อนัดแรก → ลดราคานัดถัดไป | **แย่มาก** — ราคายิ่งต่ำ หนี้ยิ่งเหลือ |
| ลดราคาถึงนัดที่ 6 ขายได้ ~1.5 ล้าน | **เลวร้ายสุด** — ขาดอีก 1.7 ล้าน SCB ทวงจากธนกร |

## ⚠️ สรุปสถานการณ์ธนกร (ผู้กู้ร่วม)

```
หนี้ SCB: ~3.2 ล้าน (+ ค้าง 3 แสน + ดอกเบี้ย)
         ↓
ขายทอดตลาด → ได้เงิน X บาท
         ↓
ถ้า X > 3.2M  → เหลือ → แบ่งให้ธนกร 50%   ✅
ถ้า X < 3.2M  → ขาด → SCB ทวงจากธนกร      ⚠️
ถ้า X << 3.2M → ขาดมาก → ธนกรเป็นหนี้ SCB  ❌
```

### สิ่งที่ธนกรควรทำ (อัปเดต)

1. **คัดค้านราคาประเมิน = สำคัญที่สุด**
   - ราคาประเมิน 2.5 ล้าน ต่ำกว่าตลาด 3.6–4.2 ล้านมาก
   - ถ้าราคาเริ่มต้นสูงขึ้น → มีโอกาสขายได้เกิน 3.2 ล้าน
   - ยื่นหลักฐาน: ประกาศขายบ้านสยามไฮวิลล์ 55 ตร.ว. = 3.6–4.2 ล้าน

2. **ไปวันทอดตลาดนัดแรก (14 ต.ค.) — ห้ามขาด**
   - ถ้าราคาต่ำเกินไป → ยื่นคัดค้านราคา ณ ที่นั้น
   - ถ้าไม่ไป → ถือว่ายอมรับราคาที่ขายได้

3. **ปรึกษาทนายเรื่องหนี้ SCB ทันที**
   - ธนกรเป็นผู้กู้ร่วม = SCB ฟ้องธนกรได้
   - ค้าง 3 แสนของปรารถนา → ธนกรอาจถูกทวงแทน
   - ถ้าจ่ายแทน → ไล่เบี้ยจากปรารถนา (ฟ้องแพ่ง)

4. **หาคนสนใจซื้อเข้าประมูล**
   - ยิ่งมีคนเข้าแข่งมาก ราคายิ่งสูง
   - บอกนายหน้า/คนรู้จักว่ามีบ้านสยามไฮวิลล์ขายทอดตลาด

## ความเชื่อมโยงกับคดีอื่น

### 1. คดีชู้ ยชพ 254/2566 (ขวัญลดา ฟ้องปรารถนา)
- ขวัญลดาชนะคดีแล้ว → **เป็นไปได้ว่าคดีนี้ (ยชพ 55/2567) คือการบังคับคดีตามคำพิพากษา** ของคดีชู้
- "ขวัญเรือน สุทธิศักดิ์" (โจทก์บังคับคดี) อาจเป็น **แม่ของขวัญลดา** หรือ **ขวัญลดาเอง** (ชื่อทะเบียนต่างกัน)
- ปรารถนาถูกบังคับขายบ้านจ่ายค่าเสียหาย — ธนกรโดนลากเข้าไปเพราะเป็นเจ้าของร่วมแปลง 2

### 2. คดีอาญา อ 1302/2567 / อ 1307/2566 (ปรารถนา ฟ้อง ธนกร)
- ปรารถนาฟ้องธนกร พ.ร.บ.คอมพิวเตอร์ — **แต่ตอนนี้บ้านปรารถนาจะถูกยึดจากคดีชู้**
- แสดงว่าปรารถนาแพ้คดีชู้ + ถูกบังคับขายบ้าน → **อาจมีแรงจูงใจฟ้องธนกรเป็นการโต้กลับ**
- ข้อมูลนี้ **เสริมคำให้การจ.6** ว่าปรารถนามีเหตุจูงใจทำลายธนกรด้วยคดีอาญา

### 3. ผลกระทบต่อธนกร
- บ้านหลุด = ไม่มีภาระผ่อน (ข้อดี)
- แต่ถ้ายอดหนี้ SCB > ราคาขาย → ธนกรอาจเป็น **หนี้ค้าง** (ถ้าเป็นลูกหนี้ร่วม)
- ทรัพย์สินที่มีค่าของธนกร (ส่วนแบ่ง 50% แปลง 2) กำลังจะถูกขาย — **ต้องรักษาสิทธิ**

## แยกให้ชัด: หนี้บริษัทพีที ≠ หนี้บ้าน

หลังหย่า ปรารถนาบอกว่ารับผิดชอบ **หนี้ของบริษัทพีที (PT Performance)**  
**บ้านไม่ได้ชื่อบริษัท** — เป็นชื่อบุคคล (ปรารถนา + ธนกร ผู้กู้ร่วม)

| | หนี้บริษัทพีที | หนี้บ้าน (SCB) |
|--|----------------|----------------|
| ลูกหนี้ในสัญญา | บริษัท / ตามที่ตกลง | **ธนกร + ปรารถนา** (กู้ร่วม) |
| ใบสลักหลังการหย่า | ปรารถนารับผิดชอบ (ตามที่บอก) | **ต้องเปิดดูว่าเขียนเรื่องบ้านไหม** |
| แชท LINE | คนละเรื่อง | ปรารถนาพูดว่าส่วนต่างบ้านเป็นของเธอคนเดียว |
| SCB ทวงธนกรได้ไหม | ขึ้นกับว่าธนกรค้ำ/กู้บริษัทหรือไม่ | **ทวงได้** เพราะเป็นผู้กู้ร่วมในบ้าน |

### ความหมาย

1. **รับหนี้บริษัท ≠ รับหนี้บ้านอัตโนมัติ** — คนละสัญญา คนละชื่อ
2. บ้าน **89/45 สยามไฮวิลล์** เป็นชื่อบุคคล ไม่ใช่ชื่อบริษัทพีที
3. แชท LINE ที่ว่า "ส่วนต่างบ้าน มีส่วนได้เสียคนเดียว" = ข้อตกลง **ระหว่างคู่หย่า** ไม่ใช่การปลดธนกรจาก SCB
4. ถ้าใบสลักหลังการหย่า **เขียนแค่หนี้บริษัท** ไม่เขียนบ้าน → เรื่องบ้านต้องใช้แชท LINE + ข้อตกลงภายหลัง

### สิ่งที่ต้องตรวจในใบสลักหลังการหย่า

- [ ] เขียนเรื่อง **บ้าน** 89/45 / คลองสาม หรือไม่
- [ ] เขียนเรื่อง **หนี้ SCB** ใครรับหรือไม่
- [ ] เขียนแค่ **หนี้บริษัทพีที** หรือไม่
- [ ] เขียนว่าปรารถนาได้บ้าน / ธนกรไม่รับผิดหนี้บ้าน หรือไม่

ถ้าใบสลักเขียนแค่บริษัท → อย่าสรุปว่าปรารถนารับหนี้บ้านในเอกสารหย่าแล้ว  
ใช้แชท LINE เป็นหลักฐาน **ข้อตกลงเรื่องส่วนต่างบ้าน** แยกต่างหาก

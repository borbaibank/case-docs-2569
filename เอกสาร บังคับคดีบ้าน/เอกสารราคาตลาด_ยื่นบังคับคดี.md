# เอกสารราคาตลาด สำหรับยื่นสำนักงานบังคับคดี

**คดี:** ยชพ. 55/2567 · สำนักงานบังคับคดีจังหวัดปทุมธานี สาขาธัญบุรี  
**ทรัพย์ที่สำคัญต่อธนกร:** แปลงที่ 2 โฉนด 188089 · บ้านเดี่ยว 55 ตร.ว. สยามไฮวิลล์ 89/45  
**ราคาประเมิน LED:** 2,559,272 บาท  
**หนี้ SCB คงเหลือ:** ~3,200,000 บาท (+ ค้าง ~3 แสน)  
**นัดขายแรก:** 14 ต.ค. 2569  
**หมายเหตุ:** ให้ทนายตรวจก่อนยื่น — ฉบับนี้เป็นชุดประกอบ ไม่ใช่คำร้องศาลฉบับสมบูรณ์

---

## เอกสารราคาตลาด คืออะไร

เจ้าพนักงานบังคับคดีตั้ง **ราคาเริ่มต้นประมูล** จากราคาประเมินของสำนักงาน (2.56 ล้าน)

ธนกรในฐานะ **เจ้าของร่วม + ผู้กู้ร่วม** มีสิทธิยื่นหลักฐานว่า **ราคาตลาดสูงกว่านั้นมาก** เพื่อ:

1. ขอให้พิจารณา **ปรับราคาเริ่มต้นให้สูงขึ้น** หรือส่งคณะกรรมการกำหนดราคาทรัพย์
2. ใช้เป็นเหตุ **คัดค้านถ้าราคาเคาะต่ำเกินสมควร** ในวันขาย
3. แสดงว่าถ้าขายได้แค่ 2.56 ล้าน จะ **ไม่พอหนี้ SCB 3.2 ล้าน** → ธนกรเสียหาย

> **สำคัญ:** แคปประกาศขายจากเว็บ **ใช้ประกอบได้** แต่ **ไม่แข็งเท่า** รายงานประเมินจากบริษัทประเมินที่ได้รับอนุญาต

## สองอย่างที่มักปนกัน — อย่าปน

| | คัดค้าน **ราคาประเมิน** (ก่อนวันขาย) | คัดค้าน **ราคาที่เคาะได้** (วันขาย) |
|--|-------------------------------------|-------------------------------------|
| ทำเมื่อไหร่ | **ก่อนนัด 14 ต.ค.** ยิ่งเร็วยิ่งดี | ในวันขาย ถ้าราคาสูงสุดต่ำเกินสมควร |
| ยื่นที่ | สำนักงานบังคับคดีสาขาธัญบุรี | เจ้าพนักงาน ณ ที่ขาย |
| เอกสารหลัก | รายงานประเมินเอกชน + ตารางเทียบราคาตลาด | หลักฐานตลาด + ขอลดเลื่อนเพื่อหาคนสู้ราคา |
| ผลที่หวัง | ราคาเริ่มต้นสูงขึ้น (ใกล้ 3.6 ล้านขึ้นไป) | ไม่ให้ขายในราคาต่ำเกินไป |
| กฎหมายที่อ้างบ่อย | กฎกระทรวงกำหนดราคาทรัพย์ / คณะกรรมการกำหนดราคา | ป.วิ.พ. ม.331 (สู้ราคา / หาคนมาสู้ราคา) |

กฎหมายใหม่เน้นว่าผู้มีส่วนได้เสีย **เข้าสู้ราคาเอง หรือหาคนมาสู้ราคา** ได้  
การยื่นแคปเว็บอย่างเดียว **ไม่การันตี** ว่าเจ้าพนักงานจะเลื่อนหรือปรับราคาให้
